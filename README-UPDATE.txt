Install:
1. Back up your current index.html and my-pc.html.
2. Copy these files into the root of your existing GitHub Pages repository.
3. Keep your existing style.css, app.js, games.html, game.html, gpus.html, cpus.html and compare.html.
4. Ensure the scanner/ folder is uploaded with Detection.exe.
